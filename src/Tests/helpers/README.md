# helpers

Shared Jest custom matchers used by [../Scratch.test.js](../Scratch.test.js), and available to any other test.

## Contents:
- [./TestHelpers.js](./TestHelpers.js): Custom Jest matchers (`ArrayEqualTo`, `ArrayCloseTo`, `VecEqual`, `MatrixEqual`, `VertexArray2DToBeCloseTo`, `VertexArray2DCircToBeCloseTo`) for comparing arrays, vectors, matrices, and vertex arrays with numeric tolerance.
