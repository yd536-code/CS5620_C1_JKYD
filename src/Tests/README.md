# Tests

A scratch Jest file for ad hoc experiments, and the shared custom matchers it uses. The engine's own tests live in `__tests__/` folders next to the code they test (for example [../anigraph/scene/__tests__/](../anigraph/scene/__tests__/README.md)).

## Contents:
- [./helpers/](./helpers/README.md): Shared custom Jest matchers used by the tests below.
- [./Scratch.test.js](./Scratch.test.js): Scratch file for ad hoc experimentation with the custom Jest matchers.
