# InstancedParticles

Rendering thousands of particles as individual scene-graph nodes would be far too slow, so this module draws them all in a single draw call using `THREE.InstancedMesh` instead — the concrete, Three.js-specific implementation that [../](../README.md)'s abstract `AParticleSystemModel3D`/`AParticleSystemView3D` classes delegate to. `AInstancedParticleSystemGraphic3D` (extends `AInstancedGraphic`) owns the mesh and a shared geometry/material (its instance count is set by `init(n)`, defaulting to `MAX_PARTICLES`), exposing `setMatrixAt`/`setColorAt` so a view can push each particle's transform and color into the mesh's per-instance buffers every frame. `AInstancedParticleSystemModel3D` is an abstract model layer on top of `AParticleSystemModel3D` that also owns a shader model/material (`AInstancedParticleSystemShaderModel`/`InstancedParticleSystemMaterial`, which adds a particle texture uniform and an `opacityInMatrix` toggle for shaders that read per-instance opacity out of the instance transform matrix, since `InstancedMesh` has no separate per-instance scalar attribute) and lazily loads that shader model once per subclass. `AInstancedParticleSystemView3D` ties the two together: each frame it iterates the model's particles and writes each one's color and transform (from the subclass's `_getColorForParticleIndex`/`_getTransformForParticleIndex`) into the graphic's instance buffers. Packing opacity into the transform, if the material reads it from there, is up to the subclass's `_getTransformForParticleIndex`.

## Contents:
- [./AInstancedParticleSystemGraphic3D.ts](./AInstancedParticleSystemGraphic3D.ts): Graphic object wrapping a `THREE.InstancedMesh`. Provides `setColorAt` and `setMatrixAt` for per-instance updates; `MAX_PARTICLES` is `init()`'s default instance count.
- [./AInstancedParticleSystemModel3D.ts](./AInstancedParticleSystemModel3D.ts): Abstract model for instanced particle systems. Manages a shader model class and material, and supports optional per-particle opacity stored in instance matrices.
- [./AInstancedParticleSystemShaderModel.ts](./AInstancedParticleSystemShaderModel.ts): Shader model and material for instanced particles: a particle texture, and an `opacityInMatrix` flag that tells the shader to read per-particle opacity from the instance matrix.
- [./AInstancedParticleSystemView3D.ts](./AInstancedParticleSystemView3D.ts): Abstract view for instanced particle systems. Iterates over particles each frame, writing per-instance colors and transforms to the graphic.
- [./index.ts](./index.ts): Barrel export for the InstancedParticles module.
