# AppState

This module holds the one global, reactive store an AniGraph application uses for anything that isn't scene-graph data: current scene reference, registered render windows, and the specs backing the Leva-based GUI control panel. `AAppState` is the abstract base — an `AObject` subclass holding named state values and GUI control specs, with `SetAppState`/`GetAAppState` module-level singleton helpers so any code can reach the current app state without threading it through every constructor. Every one of `AAppState`'s control-registration methods (`addSliderControl`, `addControlSpecGroup`, ...) is a thin wrapper around a single internal [`AControlSpecGroup`](../controlpanel/README.md). `AppState` is the concrete subclass actually instantiated by starter apps (through `CreateAppState(sceneModel)`, which returns the existing app state, with a warning, if one was already created); it adds a scene-model reference, tracked render windows, and hooks (`getReactGUIContent`) for a scene to inject custom React content into the GUI panel (see [../../Component/GUIComponent.tsx](../../Component/README.md)). `GetAppState.ts` is a thin convenience wrapper that returns the singleton already cast to the concrete `AppState` type. The [../components/ControlPanel.tsx](../components/README.md) component and [../controlpanel](../controlpanel/README.md) module both read from this module's control specs to render and update the on-screen GUI.

## Contents:
- [./__tests__](./__tests__/README.md): Jest specs for the app state.
- [./AAppState.ts](./AAppState.ts): Abstract base class for application state. Holds named state values, GUI control specs (via Leva), and coordinates the control panel. Provides `SetAppState`/`GetAAppState` singleton helpers and `AppStateEvents` enum.
- [./AppState.ts](./AppState.ts): Concrete `AppState` subclass that also holds a reference to the scene model and registered render windows, and provides hooks for injecting React GUI content.
- [./ControlPanel.md](./ControlPanel.md): Guide for scene authors on adding controls the user can interact with, and updating a control's range/options/value from code while the app runs.
- [./GetAppState.ts](./GetAppState.ts): Convenience function that returns the singleton `AppState` cast to the concrete type, avoiding the need to import both the getter and the type.
- [./index.ts](./index.ts): Barrel export for the appstate module.
