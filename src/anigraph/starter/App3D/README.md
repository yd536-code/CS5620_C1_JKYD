# App3D

The 3D-scene starting point used by CS4620 final-project scenes, structured to leave the essential per-app decisions to subclasses while handling the shared setup itself. `AppSceneModel3D` extends [../scene/ABasicSceneModel.ts](../scene/README.md) and declares `timeUpdate`, `initAppState`, and `initCamera` as abstract — every concrete final-project scene must implement these — while providing `_initDefaultCamera()` as an optional convenience (perspective camera, 90° FOV, looking down -Z) that `initCamera` implementations can call instead of building a camera from scratch. `PreloadAssets` is inherited from `ABasicSceneModel`; a subclass that overrides it calls `super.PreloadAssets()`. `AppSceneController3D` similarly extends `ABasicSceneController`, setting a black clear color, and inherits working `onAnimationFrameCallback` (which calls `model.timeUpdate`, updates the controller, and renders) and `initInteractions` from it, so subclasses don't have to implement them. `ADebugInteractionMode` (fly/orbit) is this starter's default interaction mode (via `ABasicSceneController.addDebugInteractionMode`, which `initInteractions` calls); `_basicInitInteractions()` is a helper that adds it for a subclass's own `initInteractions`. (The 2D starter, [../App2D/](../App2D/README.md), uses `APanZoomInteractionMode2D` instead, because fly/orbit has no effect on a 2D camera; see `scene/camera/README.md`.)

The 3D-only parts of the starter layer live on these two classes, not on the shared bases, so 2D scenes don't inherit them: `AppSceneModel3D` has `initPerspectiveCameraFOV`/`NearPlane`, `addPointLight`/`addPointLightToModelGraph`, and the view light (`viewLight`/`addViewLight`/`_attachViewLightToCamera`/`_detachViewLightFromCamera`). `AppSceneController3D` registers the four built-in 3D-only default model-view specs (`_addDefaultModelViewSpecs`: triangle meshes, unit quads, visible point lights, coordinate axes) and has `initSkyBoxCubeMap`; `ABasicSceneController.initModelViewSpecs()` is an empty, overridable hook.
