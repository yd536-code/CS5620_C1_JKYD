# App2D

The 2D-on-Three.js starting point for course apps (as opposed to [../App2DTwoJS/](../App2DTwoJS/README.md), the SVG/canvas backend, or [../App3D/](../App3D/README.md)) — this is what the C1 example scenes in `Scenes/C1ExampleScenes` subclass. `AppSceneModel2D` is abstract, extending [../scene/ABasicSceneModel.ts](../scene/README.md) with a 2D-appropriate default camera (`initCamera` sets up a uniform orthographic `ACameraModel2D`) and leaves `PreloadAssets`/`initAppState` for a concrete scene to fill in with its own assets and GUI controls. `AppSceneController2D` is concrete and ready to use as-is (or subclass) — on top of `ABasicSceneController` it sets a white clear color, turns on sorted object rendering (so 2D draw order behaves predictably), and uses `APanZoomInteractionMode2D` from [../interactionmodes/](../interactionmodes/README.md) as the default interaction mode, so a new scene has drag-to-pan/wheel-to-zoom navigation out of the box. (`initInteractions()` does not call `super.initInteractions()`, which would also add `ADebugInteractionMode`; that mode's fly/orbit moves the wrapped `ACamera`'s 3D pose, which a 2D camera doesn't render from.) Its default `onAnimationFrameCallback` calls `model.timeUpdate(model.clock.currentTime)`, updates the controller, and renders; a subclass that overrides it should call `super.onAnimationFrameCallback(context)` and not call `model.timeUpdate` itself, or the model updates twice per frame.

`AppSceneModel2D` holds the starter layer's orthographic camera setup (`initOrthographicCamera`, `initNormalizedOrthographicCamera`, `initUniformOrthographicCamera`, `init2DOrthoCamera`). `ATwoJSAppSceneModel` (in [../App2DTwoJS/](../App2DTwoJS/README.md), the Two.js starter) extends this class to reuse that setup; `AppSceneModel2D` has no Three.js-specific code, so it works for both backends.

- [./AppSceneController2D.ts](./AppSceneController2D.ts): Concrete 2D scene controller starter. Sets a white background, enables sorted rendering, uses `APanZoomInteractionMode2D` as the default interaction mode, and calls `model.timeUpdate` each frame.
