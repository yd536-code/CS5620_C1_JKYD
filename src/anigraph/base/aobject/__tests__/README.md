# __tests__

Jest specs for the [aobject](../README.md) module, exercised through `AObjectNode` since it's a concrete subclass of `AObject`. `AObject.test.js` checks that `uid` is a unique, non-empty string per instance, that `@AObjectState`-decorated fields (via `AObjectNode.name`) trigger `addStateListener`/`addStateKeyListener` callbacks when reassigned, and that the named-event API (`addEventListener`/`signalEvent`) delivers arguments to the right listener and doesn't cross-fire between different event names. `AObjectNode.test.js` covers the tree-structure half — parent/child wiring, `mapOverChildren`/`mapOverDescendants` traversal, the `NewChild`/`DescendantAdded`/`ChildRemoved` events fired as nodes are added to and removed from the tree, and (`AObjectNode release`) tests for `release()`'s `DescendantReleased` event: that it reaches ancestors at every depth, that it fires *after* `DescendantRemoved` (some listeners depend on that order), and that a uid-keyed registry correctly re-registers a fresh node reusing a just-released node's `uid`. Its `AObjectNode space compatibility (nodeSpace)` block tests `_addChild`'s space check against lightweight fake subclasses tagging `nodeSpace` `'2D'`/`'3D'` — same-space parenting, a mismatch in either direction throwing and leaving the child unattached, a space-untagged node being compatible with anything, a mismatch two levels deep, and `reparent()`. `../../../scene/__tests__/NodeSpaceCompatibility.test.ts` is the companion integration test against the real `ANodeModel2D`/`ANodeModel3D` classes.

## Contents:
- [./AObject.test.js](./AObject.test.js): Tests `AObject` reactive state, event listeners, and `uid` behavior.
- [./AObjectNode.test.js](./AObjectNode.test.js): Tests `AObjectNode` tree structure and parent/child/descendant events.
- [./AObjectNodeParentEvents.test.ts](./AObjectNodeParentEvents.test.ts): `NewParent` listener arguments on add `(newParent, undefined)` and removal `(null, oldParent)`, and that `NewParent`/`ChildRemoved` listeners run before `addChild`/`removeChild` return.
- [./AObjectRelease.test.ts](./AObjectRelease.test.ts): `release()` removes state listeners added to the object, `removeListener` warns instead of throwing on an unknown handle, state listener `activate()` is idempotent and handle reuse replaces the old listener, and the `stateSnapshot` getter.
- [./ASelection.test.ts](./ASelection.test.ts): `ASelection` callback counts: `set(items, false)` runs no callbacks, and `select`/`deselect` skip callbacks when nothing changes.
