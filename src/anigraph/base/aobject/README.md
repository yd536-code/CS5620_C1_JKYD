# AObject

`AObject` is the base class almost everything in AniGraph ultimately extends (models, views, controllers, particles, the asset manager, etc.), and this directory is where its two core capabilities live. `AHandlesEvents` gives any object a named-event API — `addEventListener`/`signalEvent`/`removeEventListener`, backed by an `AEventCallbackDict` per event name (see [../aevents/](../aevents/README.md)) — plus a separate `subscribe`/`unsubscribe` mechanism for holding onto *other* objects' callback switches so they can all be torn down together via `clearSubscriptions()`. `AObject` extends that with reactive state: its `state` field is a [valtio](https://github.com/pmndrs/valtio) proxy, and the `@AObjectState` property decorator (used throughout the codebase, e.g. on model position/rotation fields) makes a class field read/write through that proxy so `addStateListener`/`addStateKeyListener` callbacks fire automatically whenever it changes — this is what lets a node view stay in sync with its model without polling. `AObjectNode` extends `AObject` again to add parent/child tree structure (`addChild`, `removeChild`, `reparent`, ancestor/descendant traversal) and fires structural events (`NewParent`, `NewChild`, `DescendantAdded`, `DescendantReleased`, etc.) as the tree changes — it's the base every scene-graph model and view builds on (see [../amvc/](../amvc/README.md) and [../../scene/](../../scene/README.md)). `AObject.toJSON()` is the one canonical serialization implementation every subclass inherits (snapshot of `state`, merged with any `@ASerializableField`-tagged plain fields — see [../aserial/](../aserial/README.md)); `AObjectNode` doesn't override it. `release()` signals `DescendantReleased` on the node's ancestors *before* `_removeChild` cuts the parent link, because after that the ancestors can no longer be reached. `ASelection<T>` is a separate, general-purpose container for tracking a changing set of selected items with enter/update/exit callbacks (used for things like multi-object selection in an editor). `HasTags` and `PromiseListener` round the module out: a small interface for attaching named tags to objects, and a lightweight `Promise` wrapper that exposes synchronous `_pending`/`_fulfilled`/`_rejected` flags for checking async state without awaiting.

## Contents:
- [./__tests__/](./__tests__/README.md): Unit tests for the aobject module.
- [./AHandlesEvents.ts](./AHandlesEvents.ts): Mixin/base class that gives any object the ability to register, fire, and remove named event callbacks via `AEventCallbackDict`.
- [./AObject.ts](./AObject.ts): Core base class. Wraps instance state in a valtio proxy for reactive subscriptions, provides `uid` and `AObjectState` decorator, and supports one-time and persistent listeners. State listeners: `addStateListener` (any change), `addStateKeyListener` (fires only when one key is *reassigned*; nested edits don't count), and `addStateKeysListener`/`addStateListenerExcept` (changes under, or not under, a set of keys, nested edits included, filtered on the first segment of valtio's op path).
- [./AObjectNode.ts](./AObjectNode.ts): Extends `AObject` to form a tree node with parent/children/root pointers. Fires events (`NewParent`, `NewChild`, `DescendantAdded`, etc.) when the tree structure changes. `DescendantAdded` is signaled only for the node being added, not for that node's own descendants; this is deliberate. `AModelGraph` walks an added subtree itself (see [../../scene/README.md](../../scene/README.md)).
- [./ASelection.ts](./ASelection.ts): Generic selection container `ASelection<T>` with enter/update/exit callbacks fired as items are added or removed.
- [./HasTags.ts](./HasTags.ts): Interface for objects that support named tags with optional values.
- [./PromiseListener.ts](./PromiseListener.ts): Lightweight wrapper around a `Promise` that exposes synchronous `_pending`, `_fulfilled`, and `_rejected` flags.
- [./index.ts](./index.ts): Barrel export for the aobject module.
