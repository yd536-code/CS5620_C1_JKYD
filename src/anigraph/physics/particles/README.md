# Physics Particles

Plain-data particle types shared by physics code and the [../../effects/particles/](../../effects/particles/README.md) rendering systems, deliberately separated into a minimal interface layer and small concrete classes rather than one big particle class. `BasicParticle<V>` is the smallest possible contract (just a `position: V`); `Particle2D`/`Particle3D` extend it with dimension-specific fields, and `AParticle2D`/`AParticle3D` are the concrete classes actually instantiated, adding visibility, size, and (for 2D, via the `AParticleEuler2D` subclass) velocity and mass for simple Euler-integration simulations. `BasicInterfaceParticles.ts` defines a separate, more generic particle contract (`ABasicParticle`/`PhysicalParticle`, parameterized over a stored vector type and an interface vector type, with id, radius, and velocity) along with a few example concrete particles (`BasicParticle2D`, `BasicParticle3D`, `AParticleOther3D`) — an alternate design, not used by the engine's particle systems, that separates how position/velocity are stored from how they're exposed. Despite their names, `BasicParticle2D`/`BasicParticle3D` belong to this alternate design; they satisfy `BasicParticle<V>` (through `ABasicParticle`) but aren't the `Particle2D`/`AParticle2D` family the particle systems use. These particles start hidden (`visible` is false until you call `show()`). `AParticleEnums.ts` holds shared constants and event names (like `PARTICLES_UPDATED`) referenced across both particle-system implementations.

## Contents:
- [./__tests__/](./__tests__/README.md): Unit tests for the particle classes.
- [./AParticle2D.ts](./AParticle2D.ts): Concrete 2D particle class implementing `Particle2D` with position, depth, size, and visibility. Also defines the `ParticleProperties2D` extended interface.
- [./AParticle3D.ts](./AParticle3D.ts): Concrete 3D particle class with position, velocity, mass, size, and visibility.
- [./AParticleEnums.ts](./AParticleEnums.ts): Enums for particle defaults (`DEFAULT_MAX_N_PARTICLES`) and events (`PARTICLES_UPDATED`).
- [./BasicInterfaceParticles.ts](./BasicInterfaceParticles.ts): Abstract base classes `ABasicParticle` and `PhysicalParticle` providing a richer particle contract (id, radius, visibility, velocity), plus example concrete particles. Not used by the engine's particle systems; particles start hidden.
- [./BasicParticle.ts](./BasicParticle.ts): Minimal `BasicParticle<V>` interface requiring only a `position` property of vector type `V`.
- [./index.ts](./index.ts): Barrel export for the physics/particles module.
