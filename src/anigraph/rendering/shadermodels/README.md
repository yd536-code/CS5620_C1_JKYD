# Rendering Shader Models

The lighting-focused counterpart to [../material/shadermodels/](../material/shadermodels/README.md) — both are concrete `AShaderModel` implementations built on [../material/](../material/README.md)'s infrastructure, but these specifically model how a surface reflects light, forming a small inheritance chain from simplest to most capable. `ABasicDiffuseShaderModel` models diffuse/ambient lighting terms (the file also defines a `DiffuseMaterial` class with `setDiffuse`/`setAmbient`, but the model doesn't set `ShaderMaterialClass`, so its materials are plain `AShaderMaterial`s), and `ABlinnPhongShaderModel` extends that with a specular term (`BlinnPhongMaterial.setSpecular`/`setSpecularExp`) for shinier surfaces. `ABasicTexturedShaderModel` extends `ABlinnPhongShaderModel` directly, adding a thin `CreateMaterial` convenience that pre-binds a diffuse texture, and `ATerrainShaderModel` extends *that* further with a second height-map texture and a `texCoordScale` uniform for tiling terrain textures across a mesh. `ATexturedMaterialModel` is a separate, independent shader model (extends `AShaderModel` directly rather than the diffuse/Blinn-Phong chain) that just configures the `"blinnphong"` GLSL program with a named default diffuse texture (`marble.jpg` unless one is passed in).

## Contents:
- [./__tests__/](./__tests__/README.md): Tests for the Diffuse/Blinn-Phong model statics and the textured models.
- [./ABasicDiffuseShaderModel.ts](./ABasicDiffuseShaderModel.ts): Shader model for a basic diffuse lighting shader. Also defines a `DiffuseMaterial` subclass with typed `setDiffuse`/`setAmbient` accessors (not used by this model's own materials, which are plain `AShaderMaterial`s). Overrides `AShaderModel`'s `static getClassControlSpecGroup()` with its own shared Ambient/Diffuse sliders (one pair no matter how many materials/instances of this shader exist) -- `static AddAppState()` is the entry point scenes call, a thin wrapper that registers whatever `getClassControlSpecGroup()` returns. `AddAppState`/`CreateModel` are written once here and shared by subclasses: subclasses set `ControlSpecFolderName`, `AddAppStateByDefault` (`true` here, `false` for Blinn-Phong) and redeclare `_appStateAdded` to track their folder separately.
- [./ABasicTexturedShaderModel.ts](./ABasicTexturedShaderModel.ts): Extends `ABlinnPhongShaderModel` with a convenience `CreateMaterial` that pre-binds a diffuse texture.
- [./ABlinnPhongShaderModel.ts](./ABlinnPhongShaderModel.ts): Blinn-Phong shading model. Adds `BlinnPhongMaterial` with `setSpecular`/`setSpecularExp` accessors on top of the diffuse model. Extends its parent's `getClassControlSpecGroup()` (Ambient/Diffuse, under the `BlinnPhong` folder name) with Specular/SpecularExp, and inherits `AddAppState`/`CreateModel`. Its materials are `BlinnPhongMaterial`s.
- [./ATerrainShaderModel.ts](./ATerrainShaderModel.ts): Extends the basic textured model to support a separate height-map texture and a `texCoordScale` uniform for terrain rendering.
- [./ATexturedMaterialModel.ts](./ATexturedMaterialModel.ts): Convenience shader model that binds the `blinnphong` shader and pre-loads a named diffuse texture (defaults to `marble.jpg`).
- [./index.ts](./index.ts): Barrel export for the rendering/shadermodels module.
