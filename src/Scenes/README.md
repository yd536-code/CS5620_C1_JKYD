# Scenes

Applications (scenes) built on top of the [AniGraph](../anigraph/README.md) engine — the 2D example scenes for the CS4620 C1 assignment. `MainApp.tsx` selects which scene to run; see the [Creating a Scene](https://www.cs.cornell.edu/courses/cs4620/2026fa/assignments/docs/assignments/c1/creating-a-scene/) page of the C1 docs for how to create a new one.

## Contents:
- [./C1ExampleScenes/](./C1ExampleScenes/README.md): 2D example scenes for the C1 assignment that follow `AniGraphSceneGuides.md`.
- [./AniGraphSceneGuides.md](./AniGraphSceneGuides.md): Guidelines on where logic belongs in a scene: node models, the scene model, or the controller.
