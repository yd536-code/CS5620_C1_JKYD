# Scenes

Applications (scenes) built on top of the [AniGraph](../anigraph/README.md) engine — the 2D example scenes for the CS4620 C1 assignment. `MainApp.tsx` selects which scene to run; see [./CreateAScene.md](./CreateAScene.md) for a guide to creating a new one.

## Contents:
- [./C1ExampleScenes/](./C1ExampleScenes/README.md): 2D example scenes for the C1 assignment that follow `CreateAScene.md` and `AniGraphSceneGuides.md`.
- [./AniGraphSceneGuides.md](./AniGraphSceneGuides.md): Guidelines on where logic belongs in a scene: node models, the scene model, or the controller.
- [./CreateAScene.md](./CreateAScene.md): Guide to creating a new AniGraph scene.
