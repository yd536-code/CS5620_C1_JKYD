# TutorialScene nodes

Your node models and views go here, one class per file, as you work through the C1 tutorial. Add each file to the Contents list below, and re-export it from `index.ts`.

## Contents:
- [./index.ts](./index.ts): Re-exports the classes in this folder.
- [./TutFactories.ts](./TutFactories.ts): To build polygons.
- [./TutShapeModel.ts](./TutShapeModel.ts): To instantiate each entity
- [./TutGroupModel.ts](./TutGroupModel.ts): To instantiate each group of entity(ies)
